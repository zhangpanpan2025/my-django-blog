# My Django Blog - 个人博客系统

这是我的第一个Django全栈项目，一个功能完整的个人博客系统，用于展示Python Web开发能力。

## 🚀 项目简介
- **开发目的**：学习Django框架，为寒假实习准备技术作品
- **核心功能**：用户认证、文章管理、后台管理、前端展示
- **技术栈**：Python, Django, SQLite, HTML/CSS

## 📁 主要功能
- ✅ 用户注册/登录系统
- ✅ 文章的创建、编辑、删除、查看（CRUD）
- ✅ Django Admin后台管理界面
- ✅ 响应式前端文章列表页面

## 🛠️ 技术要点
- Django MTV设计模式实践
- 数据库模型设计（Article模型）
- 前后端数据交互实现
- Git版本控制与GitHub部署

## 💻 快速运行
```bash
git clone https://github.com/zhangpanpan2025/my-django-blog.git
cd my-django-blog
pip install django
python manage.py migrate
python manage.py runserver
